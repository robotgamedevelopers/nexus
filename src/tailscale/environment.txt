# The process environment the Tailscale shim's linked code reads, and what the shim does about each read.
# Checked by `go run ./environment -check` (cmake/tailscale.cmake's nexus_tailscale_environment_check, in CI): every
# environment read in the Go source the shim links on any platform nexus builds it for (the standard library included,
# nexus's own code not) must be here, and every line here must name a read that is still there. shim/environment.go is
# generated from this file (`go run ./environment`). Fields are separated by tabs: name (or @place for a read whose name
# the source computes), refuse | forced | allow, and why.
#
# refuse: nts_start refuses while it is set, to anything (even empty), as Go or the C library sees the environment.
# forced: the shim sets it itself before every start.
# allow: read, but it cannot change the control server, sign-in, logging, uploads, TLS keys or trust, or debugging.
#
# Not seen by the scan: what the Go runtime reads by its own means (GODEBUG, GOGC, GOMAXPROCS, GOTRACEBACK, ...), which
# is why GODEBUG is also refused below.
