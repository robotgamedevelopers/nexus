# Licences of the Go modules the Tailscale shim links

Generated by `go run ./notices -tags <the omissions>` in `src/tailscale` (do not edit by hand; `cmake/tailscale.cmake` runs it): every module that `go list -deps ./shim` names for darwin/arm64, darwin/amd64, linux/amd64 and windows/amd64 with cgo on and the build tags the shim is built with (the feature omissions in `src/tailscale/pins.cmake`), at the versions `go.mod` pins, with the licence its licence files state. CI fails when this file differs from what the program writes (`-check`).

Toolchain: go1.27.4 (the Go standard library and runtime, BSD-3-Clause, are linked too). Modules: 37 (Apache-2.0 5, Apache-2.0 + MIT + BSD-3-Clause 2, BSD-2-Clause 2, BSD-3-Clause 17, MIT 11). Every one may be combined with nexus's AGPL-3.0.

These modules' licences require their texts to go with any binary that links the shim. Nothing carries them yet: no nexus binary that links the shim ships until it does (docs/roadmap.sexp, task `t-ts-licence-texts`). The texts are the licence files named here, in each module at its version.
