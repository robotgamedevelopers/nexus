# Licences of the Go modules the Tailscale shim links

Generated by `go run ./notices` in `src/tailscale` (do not edit by hand): every module that `go list -deps ./shim` names for darwin/arm64, darwin/amd64, linux/amd64 and windows/amd64 with cgo on, at the versions `go.mod` pins, with the licence its licence files state. CI fails when this file differs from what the program writes (`go run ./notices -check`).

Toolchain: go1.27.1 (the Go standard library and runtime, BSD-3-Clause, are linked too). Modules: 42 (Apache-2.0 5, Apache-2.0 + MIT + BSD-3-Clause 2, BSD-2-Clause 3, BSD-3-Clause 19, ISC 1, MIT 12). Every one may be combined with nexus's AGPL-3.0.

A binary that links the shim carries each module's licence file named here, from the module at its version.
